Ashok Dairy — installable counter app (design build)
====================================================

INSTALL
  1. Put this folder online (drag it onto app.netlify.com/drop, or GitHub Pages).
  2. Open the https link on the device.
  3. Android/Chrome: menu -> Install app.  iPhone/iPad Safari: Share -> Add to Home Screen.

WHAT IT KEEPS
  Sales, price edits and customer credit are saved on that device.
  Product photos are dropped/picked per device (tap a product tile on the Items tab).

PRINTING
  Open a bill from Sales -> Print. Prints an 80 mm thermal slip.
